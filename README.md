# Arm Clearance · 连续手臂与手部避碰

v0.2.12，用于手臂避碰粗修，输出后由使用者播放检查并进行二次修复。

插件只修正左右上臂、前臂和手腕共六根骨骼的旋转。手掌与手指参与碰撞检测，手指沿用原动画；原动作保留，结果写入新的 Action，骨骼位置、缩放、层级与蒙皮保持。

## 文件行为

正式插件不主动创建任何工程外文件，不生成报告、日志文件、磁盘缓存、快照或临时数据文件，也不向 Blender 工程写入报告文本。运行进度仅在面板与控制台显示；修正结果和必要的复核标记保留在工程的 Action 中，由使用者自行保存工程。

研发记录工具和测试报告不随插件分发，正式插件没有将诊断数据写到插件安装目录、用户目录或工程旁边的功能。

## 本版变化

- 按检测、求解、动作还原、连续性、静止约束、追加补修、烘焙与安全恢复八个功能区域组织代码。
- 加强前臂、手腕、肘腕路径及手掌整体朝向对原动作的保留，减少额外运动。
- 根据原动作的明显姿态切换建立时间分段，隔离跨段平滑、静止控制、补修窗口和手部包络的时间影响。
- 移除正式插件的报告持久化，避免报告文本积累造成编辑、切帧和保存卡顿。
- 保留有效末帧，修复完整烘焙到源动作末端时出现多余 end+1 尾键的问题；局部烘焙保留必要的过渡保护。
- 继续提供原动作对比、上一版结果查看、取消和异常恢复，以及实际表面复核与最多三轮追加补修。

## 安装与使用

实测环境为 Windows / Blender 5.2.2。元数据最低版本为 Blender 4.4，其他版本尚未完成兼容性验证。

1. 从 [v0.2.12 发布页](https://github.com/BlankWX/arm-clearance/releases/tag/v0.2.12) 下载 `arm_clearance-v0.2.12.zip`。在 Blender「编辑 → 偏好设置 → 插件」中选择「从磁盘安装」，安装并启用插件。更新旧版后重启 Blender。
2. 备份工程，在 3D 视图侧栏打开「手臂避碰」，点击「识别当前角色」，核对骨架、网格、检测材质和六根目标骨名称。
3. 核对场景开始帧和结束帧，点击「分析并烘焙场景范围」，等待求解、烘焙及实际表面复核结束。运行中可按 Esc 取消。
4. 切换原动作与烘焙动作，完整播放检查。复核未通过的候选会明确标记为待修正，不能当作避碰已完成；确认效果后自行保存工程。

升级插件不会改变已有烘焙结果，需要重新运行烘焙才能应用新版规则。

## 输入条件与限制

当前针对一个骨架、一个蒙皮网格和一个活动 Action。六目标骨需要四元数旋转模式，骨骼层级应与实际手臂关联一致；骨架对象使用正的均匀缩放，网格使用指向该骨架的线性蒙皮并关闭「保留体积」。活动 NLA、目标骨约束、驱动和曲线修改器等需要先烘焙为可直接处理的动画，其他几何修改器按入口提示处理。

已对一个测试动作的头后、胸前两个完整动作区间进行原动作对照，并在 1–520 帧上下文复核 1039 个整数帧和半帧采样。跨段隔离减少了额外运动和失败采样，但仍有切换处残留；胸前起手等局部指标存在退步。无报告版完成了生命周期、实际安装包和安装保护核验，没有重新进行全片运动验收。

尚未完成多动作通用性、全片观感或长动作性能验收。半帧采样不能保证连续时间内绝无穿模，安全间距设置也不等同于所有表面均已证明达到该距离；同手手指之间的互穿不在当前修复范围内。

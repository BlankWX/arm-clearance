# 静止段保护

原有速度、加速度项限制的是修正轨迹的变化速度。它们能抑制突跳，但允许原动画静止时出现缓慢变化的修正；因此“连续”不等于“保持静止”。

`stationary.py` 从本次采样的原动作识别完整双臂保持姿态：六根目标骨骼的局部旋转，以及双腕位置，连续至少 16 帧保持不变。四元数先归一化并处理正负等价；变化与整段起点比较，避免将缓慢累积的真实动作误认为静止。单个肘或腕不动而其他目标骨骼在动时，不启用保护。

静止段覆盖的三次样条控制点共享修正值。求解器仍然优化该姿态的避碰修正量，并逐帧使用身体、双臂、手掌和手指的碰撞几何；没有直接将原姿态锁死，也没有删除任何碰撞项。共享控制点保留样条的 C2 衔接，不在烘焙后硬改逐帧旋转。

控制变量、投影梯度及搜索方向遵守同一等值约束。追加修复若涉及一个共享组，整组共同调整，因此静止保护不会在 warm 修复中失效。所有组仍需通过既有真实网格复核和深身体代理残差检查；无法同时满足的结果保留待复核状态，不能因手臂已静止就视为成功。

没有完整双臂静止段时不进入控制点投影分支，保留原有浮点求解路径。安全间距、姿态保留、手腕平移软限制、迭代预算、速度/加速度权重和手指动画处理规则均保持不变。

回归覆盖见 `tests/test_stationary.py`；真实角色的帧范围和 A/B 结论记录在 `VALIDATION.md`。私有角色工程和测试缓存不进入源码包。

静止开始/结束附近最多 24 帧的衔接区增加局部样条结点，保留原有三次样条的表达空间与 C2 连续性，允许运动恢复后及时避让，避免用大幅肩部转动补偿过慢的修正释放。其他位置沿用原结点间距。时间预条件矩阵投影到共享控制点的正交独立变量空间，仍使用同一目标函数和线搜索验收。

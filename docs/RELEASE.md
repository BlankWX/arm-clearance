# v0.2.7 静止段保护与累计性能更新

发布日期：2026-10-24；功能验证日期：2026-10-22。作者 BlankWX，GPL-3.0-or-later。仓库：[BlankWX/arm-clearance](https://github.com/BlankWX/arm-clearance)，发布页：[v0.2.7](https://github.com/BlankWX/arm-clearance/releases/tag/v0.2.7)。本版累计包含 v0.2.4 的控制台进度、v0.2.5 的长动作矩阵修复和 v0.2.6 的距离查询及表面复核优化。

## 发布说明

Arm Clearance v0.2.7 修复双臂原动作保持静止时，烘焙修正仍缓慢旋转的问题。六根目标骨骼旋转和双腕位置共同保持至少 16 帧时，共享连续的避碰修正姿态，主优化和追加修复均生效；未检测到完整双臂静止区间的任务保留既有求解路径。保持安全间距、姿态保留与平滑等默认参数，以及身体、双臂、手掌和手指检测。

2026-10-22 的功能验证仅覆盖 1–400、1910–1989、3720–3799、5160–5239，共 640 个不同整数帧。1–360 帧烘焙姿态保持恒定，1–400 的 799 个整帧/半帧表面采样无相交；后三段的烘焙、播放、动作指标与碰撞报告和 v0.2.6 完全一致，最终命中仍为 1、0、1，保留已有的待复核状态。未运行本版全片或完成全片原速视觉验收，开头各代理/姿态指标的变化和测试边界详见 [验证记录](VALIDATION.md)。

安装选择 **arm_clearance-v0.2.7.zip**。更新作用于之后执行的烘焙，现有 Action 不会被自动改写。支持环境及使用方法见 README；已有任务运行时应先结束任务，再安装并重启 Blender。

- 许可证：`GPL-3.0-or-later`

## Release 说明

Blender 动画的双臂与手部避碰插件，通过整段平滑求解和可切换的 Action 烘焙，尽量减少动作变化与相邻帧跳变。

v0.2.3 减少身体距离查询中的无效计算，并缓存相同参数下的时间矩阵分解。固定 174 帧样本上，单次目标函数和梯度计算耗时降低约 19%–36%，完整烘焙结果曲线与 v0.2.2 相同。这是单次计算的测量，没有有效的整段烘焙提速比例。

安装时下载 `arm_clearance-v0.2.3.zip`，在 Blender 插件设置中选择“从磁盘安装”。不要将源码归档当作安装包。已验证 Windows / Blender 5.2.2 LTS；其他 Blender 版本尚未完成兼容性验证。

支持上臂、前臂、手腕修正；手掌和手指参与检测，保留手指原动画曲线。原动作和完整烘焙结果分别保留，可切换对比；复核失败或未完成的完整结果会明确标记。使用后需要正常保存 `.blend`。

当前版本为早期版本，存在绑定和检测范围限制；开发案例仍有两处相交记录需复核。详情参见 README、更新记录及 `docs/VALIDATION.md`。

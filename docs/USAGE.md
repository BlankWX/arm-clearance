# 使用补充

## 参数

| 参数 | 默认值 | 作用 |
| --- | ---: | --- |
| 安全间距 | 0.001 | 碰撞优化中的目标间距；实际效果受模型尺度、网格与代理近似影响 |
| 大臂姿态保留 | 100 | 越高越倾向保留上臂姿态，由前臂和手腕承担修正；不是旋转硬上限 |
| 手腕平移软限制 | 0.010 | 超出距离会增加惩罚，不是严格的位移上限 |
| 修正速度约束 | 10 | 约束相邻时刻修正的变化 |
| 修正加速度约束 | 3000 | 约束修正的加速度，减少跳变 |
| 优化迭代上限 | 600 | 主优化的总迭代预算；追加修复会单独显示进度 |
| 身体网格保留率 | 0.10 | 身体代理简化参数；最终仍对真实变形网格进行复核 |

距离按照实现中的骨架坐标计算，应结合角色尺度检查；界面会按 Blender 距离单位显示。不要将默认数值直接当成所有模型都适用的物理间距。提高保留或平滑权重可能减少动作变化，也可能增加未解决的相交。

## 工作范围

插件读取场景开始帧和结束帧，不读取当前选中的关键帧范围。计算使用该范围内的原动作；即使当前激活的是已有插件结果，也会根据关联信息追溯原动作重新求解，而不是不断叠加修正。

烘焙修改位于原 Action 的副本中，原 Action 曲线保持不变。仅写入六根目标骨骼的旋转和双腕位置，其余通道继承原动作。在工作范围两侧各一帧设置过渡保护；过渡区外尽量保持原曲线。

## 原动作与结果

完成后，当前活动 Action 会切到新结果。使用 **切换原动作 / 烘焙动作** 比较；已有上一版通过结果时，可使用 **查看上一版结果**。重复运行会更新这些结果关联。

完整结果即使复核未通过也不会被当作无效数据删除。原动作、保留的结果和报告设为持久保存数据，仍需要用户正常保存 `.blend` 文件。

## 取消与失败

按 `Esc` 取消时，会恢复运行前的活动 Action、动作槽、帧和静态姿态。只有已经完成的烘焙检查点才会保留；还在采样或尚未形成完整烘焙时取消，不会生成一个看似完成的结果。

| 状态 | 含义 |
| --- | --- |
| `complete` / Action 的 `passed` 标记 | 当前离散表面复核与代理残留门槛通过 |
| `needs_review` | 完整烘焙已保留，但复核发现问题 |
| `unverified` | 已保留完整烘焙检查点，最终复核未完成 |
| 错误或提前取消 | 查看状态文本和报告，检查是否已生成可保留的完整结果 |

`passed` 仅对应当前检查范围、检测类别和采样时刻，不保证任意中间时刻或未纳入表面的所有接触都已解决。

## 报告与问题反馈

在 Blender 文本编辑器中选择名称以 `ArmClearance_V2_Report_` 开头的文本数据块。报告是 JSON，包含工作范围、优化指标、真实表面检查、问题帧及保留结果的信息。插件不会自动向外部目录导出这些文本。

反馈问题时提供插件版本、Blender 版本、工作范围、骨骼层级、目标骨骼约束情况和复现步骤。可提供裁剪后的报告；分享工程前自行去掉不适合公开的模型、贴图或个人信息。
